Piedra, Papel o Tijera

## Integrante
- Kennya Alomoto
## Objetivo del sistema
Desarrollar en Python un juego de consola de Piedra, Papel o Tijera contra el computador, aplicando condicionales, bucles, y listas. Siguiendo los diagramas diseñados previamente.

## Descripción de funcionalidades
- El usuario elige piedra, papel o tijera (1, 2 o 3) y se valida la opción.
- El computador genera su jugada de forma aleatoria.
- El sistema compara las jugadas y muestra si hubo empate, ganó el usuario o ganó el computador.
- Al terminar cada ronda se pregunta si se desea jugar de nuevo (ciclo `while`).
- Un diccionario lleva el marcador y una lista guarda el historial de rondas.
- Al salir se muestra un resumen con las rondas jugadas, las victorias, los empates y el historial.
